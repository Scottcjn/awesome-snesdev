# Contributing

Thanks for helping build a better list of SNES / Super Famicom development resources.

## Guidelines

- **One resource per pull request** makes review easier.
- The resource should be **real, usable, and reasonably maintained** (or historically significant — note it if so).
- Place it in the **most appropriate section**, and keep sections roughly ordered.
- Use this format, one line, no emoji, factual (not promotional):

  ```markdown
  - [Name](https://link) - Short description of what it is.
  ```

- Prefer **HTTPS** links to official sources, and verify the link works before submitting.
- No duplicates — search the list first.
- If a resource doesn't fit an existing section, propose a new one in your PR.

## Disclosure

If you're affiliated with the resource you're adding (author, maintainer, etc.), please say so in the pull request.

## What belongs here

Tools, libraries, documentation, and projects for developing software for the
Super Nintendo Entertainment System / Super Famicom — assemblers, C toolchains, emulators
and debuggers, graphics and audio tools, hardware references, example projects,
and community hubs.
